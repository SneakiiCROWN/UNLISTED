# Source and build boundary

This is the reviewed code/scene snapshot of the verified Presence continuation, source checkpoint 08bab003a735880cdc2b16171667fc1af1ffd937 and runtime checkpoint 1974fd4bc8ce3429b7dbed89cda20b05263c8ead.

The complete active project, original assets and full local Git history remain preserved outside this public repository. This is a new public repository, not a rewritten copy of that history. No assets/ media, private logs, QA saves, conversion inboxes or original sound/font collections are published here. Asset references in scenes and scripts are intentional; a source ZIP alone is not a complete playable build.

Use the Windows prerelease to play. Public code can be inspected without the restricted assets. A complete local development checkout is required to rebuild, using tools/build_local_release.py. That script copies source into isolated temporary staging before importing/exporting/testing. It does not change the development checkout or player saves.
