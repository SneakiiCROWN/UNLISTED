# UNLISTED

A psychological horror investigation at 17 Briar Lane. Eli Ward answers a service call connected to his father Simon's disappearance in 1998.

**Current prerelease: 0.5.5 Last Departure.**

## Download and play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/UNLISTED/releases/download/unlisted-v0.5.5-last-departure-public-test-20261021/UNLISTED-Windows-Last-Departure-Test.zip).
2. Extract the ZIP into a new folder.
3. Open **UNLISTED.exe**. No editor or coding tools are needed.

GitHub's Code / Download ZIP is source, not the playable game. Keep older versions for rollback. [v0.5.4 Cellar Repair remains available](https://github.com/SneakiiCROWN/UNLISTED/releases/tag/unlisted-v0.5.4-cellar-repair-public-test-20261020).

## What changed?

Restoring and then isolating the service system now connects to the disputed 1998 attendance call. A mechanical relay record becomes readable; the office carries historical evidence explaining why the call was reissued.

The final interaction remains the porch register. Before the decision, a short, controllable recount uses footsteps in the actual hall, practical lighting and a changed physical sheet. Both original endings and their eligibility remain intact. Pause, mid-sequence saves and an optional pause-menu skip support recovery.

The clearer roof-aware foreground rain from the intervening development pass is included. The cellar navigation repair, impossible room, Eli/Simon investigation, first-person work, configurable Modern PSX presentation and existing saves are preserved. No rejected character study replaces the Surveyor.

## Verification and limitations

Both complete exported routes start with New Game, use normal movement and interaction, solve the valves, cross the repaired cellar aisle, encounter the live Surveyor, die/retry, escape and reach each ending. Separate checks cover recount recovery, impossible-room restoration, hiding/story mode, completed saves, layouts and 1080p / 1440p / 3440x1440 views. See VERIFIED_CHECKPOINT.json and LAST_DEPARTURE_MILESTONE.md.

This remains an alpha. The new climax is a short environmental sequence, not a finished full-length game. Surveyor character art is unfinished; its new licensed Blender source library has not been promoted. Broader environmental furnishing and sound variety still need work. Human retesting, subjective audio quality and artistic approval remain pending. Earlier NVIDIA driver crashes have no confirmed root cause; final GPU tests run serially. See KNOWN_LIMITATIONS.md.

## Keep your progress

Extract each release into its own folder. Existing saves and settings remain in `%APPDATA%/UNLISTED`; this update does not reset them. Development testing uses isolated input and separate checkpoint files. Do not delete app data when updating.

## Requirements and licensing

64-bit Windows and a Vulkan-capable graphics driver for Godot Forward+. Original code is source-available under LICENSE.txt. Third-party rights remain intact; public availability is not a blanket asset-reuse licence.
