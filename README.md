# UNLISTED

A psychological horror investigation at 17 Briar Lane. Eli Ward answers a call connected to his father Simon's disappearance in 1998.

**Current prerelease: 0.5.6 Field Return.** This is still a short alpha, not a finished full-length game.

## Download and play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/UNLISTED/releases/download/unlisted-v0.5.6-field-return-public-test-20261021/UNLISTED-Windows-Field-Return-Test.zip).
2. Extract it into a new folder and open **UNLISTED.exe**.

GitHub's Code / Download ZIP contains incomplete public source, not the playable game. The [previous 0.5.5 release](https://github.com/SneakiiCROWN/UNLISTED/releases/tag/unlisted-v0.5.5-last-departure-public-test-20261021) remains available for rollback.

## What changed

Eli's motive, Simon's original report and the ending choices have clearer context. New games include a physical evidence puzzle: use a heavy loose object to hold a mechanical release while recovering the original. The shed fitting now has a use, with alternative weights available. Signing the porch register returns control; leaving through the gate completes the departure.

Crouching changes the actual collision capsule and a maintenance screen provides sight-blocking cover. The utility bench is moved away from the back-door route. More existing work/kitchen objects can be carried. Temporary enemy vocals are quieter and less frequent. The impossible room retains unseen, closed-door safeguards with variable timing. The earlier archive furnishings and sheltered window-rain repair are included.

The Surveyor's replacement character art is **not finished**. No rejected study is active. The game needs more substantial authored progression, environmental detail, sound variety and human assessment. See [milestone details](FIELD_RETURN_MILESTONE.md) and [known limitations](KNOWN_LIMITATIONS.md).

## Verification and saves

Native automated Windows playthroughs cover both choices, live capture, death/retry, escape, physical evidence recovery and departure. Final focused checks cover the corrected register layout at 1080p, 1440p and 3440x1440, crouch/cover, saving and legacy endings. The full-route captures precede a final text-only width correction; that correction was retested separately. These are not human horror/art/audio approval. See VERIFIED_CHECKPOINT.json.

Existing saves/settings remain in `%APPDATA%/UNLISTED`. Extract updates separately; do not delete app data. Older checkpoints keep their original completion route. Start New Game to play the expanded investigation.

## Requirements and licensing

64-bit Windows and a Vulkan-capable graphics driver for Godot Forward+. The public repository deliberately omits licensed media, private logs, saves and private Git history. Rebuilding requires the complete licensed local checkout. Original code is source-available under LICENSE.txt; third-party rights remain intact. The Windows ZIP includes required notices. See THIRD_PARTY.md and ThirdPartyNotices.

[Report a bug](https://github.com/SneakiiCROWN/UNLISTED/issues) with the version and reproduction steps. Keep personal saves and private logs out of public reports. Optional owner vocal recordings remain documented in OWNER_RECORDING_CUES.md.
