## Night Arrival

- Eli's parked station wagon establishes how he reached the gate, with wet materials, fitted collision and clear walking routes.
- A brief physical torch exchange opens the actual cap and removes/inserts a supported battery pack. Movement, keyboard/controller input, reduced motion, pause, save/load, pickup, death and retry are covered.
- A stronger modern PSX world presentation uses consistent square pixels and restrained colour dithering while UI stays sharp. Clean / Modern PSX / Stronger Retro and a saved colour-effect strength slider keep it adjustable. Existing choices remain.

F / RB changes light; T / Y fits a pack, or hold with no spares at low charge to wind the backup; V / D-pad Down taps a loose contact. Put carried objects down before servicing the torch.
