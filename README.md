Newer source checkpoints contain an **unfinished director pass**: story continuity, kitchen contact and supported-mass repairs. See [progress](DIRECTOR_PASS_PROGRESS.md) and [verification](DIRECTOR_PASS_VERIFICATION.md). No newer public Windows download is claimed.

## Play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/UNLISTED/releases/download/unlisted-v0.8.0-dead-line-public-test-20261022/UNLISTED-Windows-Dead-Line-Test.zip).
2. Extract into a new folder and open **UNLISTED.exe**.
3. New Game includes all current investigation content. Older saves retain their prior completion conditions.

Keep `%APPDATA%/UNLISTED`. GitHub Code / Download ZIP is incomplete public source, not the playable game. [0.7.0 Under the Floor](https://github.com/SneakiiCROWN/UNLISTED/releases/tag/unlisted-v0.7.0-under-the-floor-public-test-20261022) and earlier releases remain available for rollback.

See [verification](DEAD_LINE_VERIFICATION.md), [release notes](DEAD_LINE_RELEASE_NOTES.md) and VERIFIED_CHECKPOINT.json.

No rejected character study is active. Human horror, story, art, subjective listening and first-playthrough assessment are pending. Automated known-route time is not player duration.
