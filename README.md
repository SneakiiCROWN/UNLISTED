# UNLISTED

A psychological horror investigation at 17 Briar Lane. Eli Ward answers a call connected to his father Simon's disappearance in 1998.

**Current prerelease: 0.6.0 The Missing Minute.** Still a short alpha; the 30-60-minute production target is not yet achieved.

## Download and play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/UNLISTED/releases/download/unlisted-v0.6.0-missing-minute-public-test-20261021/UNLISTED-Windows-Missing-Minute-Test.zip).
2. Extract into a new folder and open **UNLISTED.exe**.
3. Start **New Game** for the added investigation. Older saves retain their previous completion route.

GitHub's Code / Download ZIP contains incomplete public source, not the playable game. [0.5.6 Field Return](https://github.com/SneakiiCROWN/UNLISTED/releases/tag/unlisted-v0.5.6-field-return-public-test-20261021) and all earlier releases remain available for rollback. Saves/settings remain in `%APPDATA%/UNLISTED`; do not delete them when updating.

## The Missing Minute

Simon's torn report now leads to a graphite-rubbing interaction, a tunable receiver, a furnished bedroom memory and a physical missing page. The discovery gives the final porch choices personal context. A quiet window appearance can become a real pursuit if approached outside. Existing rain, woodland, physical evidence puzzle, crouch/hiding, impossible room, both endings and lane departure are preserved.

The Surveyor's replacement character art is **not finished**; no rejected study is active. More substantial exploration, environmental detail and sound variety remain production work. This release has not received human horror, narrative, artistic or audio approval. See [release notes](RELEASE_NOTES.md), [verification](MISSING_MINUTE_VERIFICATION.md) and [known limitations](KNOWN_LIMITATIONS.md).

## Verification

Actual exported Windows checks cover mouse rubbing, tuning, physical drawer/page interactions, room-observation guards, save/retry, outside pursuit, legacy saves, both earned ending branches and 1080p/1440p/3440x1440 layouts. The continuous route is one fresh New Game path plus an alternate from its earned checkpoint. Final delivery corrects one register sentence after that recording and retests final layouts/prerequisites. This is not human playtime or horror approval. Hashes and scope are in VERIFIED_CHECKPOINT.json.
