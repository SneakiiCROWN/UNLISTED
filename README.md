## Play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/UNLISTED/releases/download/unlisted-v0.8.1-spare-place-public-test-20261022/UNLISTED-Windows-Spare-Place-Test.zip).
2. Extract into a new folder and open **UNLISTED.exe**.
3. New Game begins outside the front gate. Knock once at the house, then press again to open it fully. Afterwards the door works normally.

Keep `%APPDATA%/UNLISTED` and previous builds. Older saves retain their existing route and ending eligibility. [0.8.0 Dead Line](https://github.com/SneakiiCROWN/UNLISTED/releases/tag/unlisted-v0.8.0-dead-line-public-test-20261022) and earlier releases remain for rollback. GitHub Code / Download ZIP is incomplete public source, not the playable game.

## The Spare Place

An optional investigation follows the disconnected counter's impossible arrival: a covered utility cot, an impossible birthday card and a reflection that contradicts the empty bed. Discover what the house claims to remember, then survive its search. Both existing departures remain attainable.

The director pass also reconciles Eli's evidence and journal, repairs kitchen and lounge support, gives nine loose props shared physics, and makes the maintenance release follow actual supporting contacts. Quiet, limited positional events sometimes disturb empty rooms. The Surveyor faces and searches more naturally; its character model is unchanged.

The impossible room, bedroom memory, rubbing, underfloor rack, Dead Line, rain/property, hiding, saves and accessibility controls remain.
