# UNLISTED 0.9.3 / Night Arrival

A parked station wagon now grounds Eli's arrival at the front gate. It uses a properly scaled PSX asset, wet material response and fitted mesh collision, with open walking space around it and an unobstructed gate/lane.

The torch now has a brief physical battery exchange: the actual rear cap opens, the existing left hand removes and seats the pack, and the cap closes. Keyboard and controller use the same action. Movement remains available, repeated presses cannot spend extra packs, and pause, save/load, real pickup, lethal capture and retry have focused exported-game coverage. Reduced motion removes the roll; hidden hands retain functional replacement.

The world presentation has a clearer modern PSX identity: consistent square world pixels, restrained RGB555-style colour reduction and stationary dithering. Interface text remains sharp. Clean, Modern PSX and Stronger Retro remain selectable, with a saved colour-effect strength slider. Existing settings are preserved; new settings default to Modern PSX.

The historical reel, useful battery budgets, rare optional loose contacts, controller controls and connected service exit from Field Test remain. There is no new Surveyor model or story expansion in this presentation/equipment milestone. Both ending routes retain the accepted Field Test full-route baseline; the changed systems receive targeted Windows testing rather than another identical full-route run.

Extract the Windows ZIP into a NEW folder and run UNLISTED.exe. Keep previous builds and AppData/UNLISTED. F / RB changes light, T / Y replaces a spare pack; with no spares, hold the same control at low charge to wind the backup. V / D-pad Down taps an occasional loose contact. Put carried objects down before changing packs.
