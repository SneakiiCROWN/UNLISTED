# Phase 3 - The Living Property (isolated)

Built on private Phase2 e889552 and safe public 0e276fb. Ordinary production
remains 9e09084; no production merge, engine change or public playable release.

Changed systems:
- graphics_phase3_property.gd: opt-in composition using property_finish batching,
  approved exterior prototypes and existing textures. Real shallow garden beds,
  matching terrain collision, finer near-ground sampling and broad rolling far
  terrain replace the steep square outer rim. Existing physical tree meshes and
  colliders move with their support grade. New middle/distant trees receive mesh
  collision. Established front, lane, service and shed route grades are retained.
- Coarse bush render batches are hidden only in this opt-in study, replaced with
  connected twig/leaf sprays and clustered grass. Foundation splash aggregate and
  two supported fence offcuts use existing licensed resources and materials.
- phase2_ground.gdshader has a default-off property_detail uniform, adding organic
  soil/leaf transitions. No competing ground shader or added reflection system.
- Phase3 disables the precomputed window room return until narrative state gating
  is approved. Clear glass/rain visibility remains. Live probes stay excluded.
- graphics_study.gd adds ten labelled property views and optional focused route
  verification; run_graphics_study.py adds explicit isolated flags. Original,
  Balanced and Enhanced remain comparable. Existing Phase1/2 flags keep behavior.
- graphics_phase3_route.gd exercises real movement, gate interaction, shed/rear
  doors, save/load, pause/resume, death-screen checkpoint retry, crouch recovery,
  AI sight and a staged physical Surveyor walk. It does not claim a full naturally
  earned investigation, combat death, all hiding encounters or both endings.
