# UNLISTED — Private Integrated Playable QA

**PRIVATE QA — STABILITY NOT CLEARED**

Extract the entire Windows ZIP into a new folder. Launch UNLISTED.exe normally.
Do not run it from inside the ZIP. Previous builds and releases remain available.
This is the full investigation, not the automated graphics tour.

The original intermittent idle-menu crash has not been conclusively fixed.
A nonfatal null-particle rendering error also recurred during ultrawide ending
checkpoint recovery. This candidate has not passed full rendering acceptance. Save
regularly. If it closes unexpectedly, retain the log and note the time and what
was happening; no personal playtest is required to continue development.

## Graphics

Open Settings > Display > Property atmosphere:

- Original PSX: established appearance and the default fallback.
- Balanced Atmosphere: integrated terrain, forest, wet materials, lit rain and glass.
- Enhanced Atmosphere: Balanced plus optional heavier fog/reflection/shadow effects.

Changes save automatically. Fully quit and reopen the game to apply an atmosphere
choice. Returning to Main Menu is not sufficient. Your existing retro strength,
visibility and accessibility choices remain independent. The Display page scrolls.

## Controls

Use Settings > Input for the current keyboard and controller mapping. Pause with
Escape / controller Start. Use the contextual interaction prompt; the journal is
available when you need to recall discoveries. Settings include controller
sensitivity, captions, reduced motion, reduced flicker and Story mode.

Ordinary startup has no test overlays, staged Surveyor, automatic puzzle solutions
or artificial ending triggers. Separate development tools remain separate.

## Player data and limits

This build uses the existing UNLISTED save/settings location. Verification uses
isolated test files and checks the owner's real files remain unchanged. Do not
copy test checkpoints over your own save. Previous save compatibility is retained;
keep the preserved rollback builds if you need to compare versions.

The Surveyor's current approved model remains. This phase does not claim to finish
character art, story pacing or the entire game. Human artistic approval, emotional
impact and first-playthrough duration are still pending. No new public release.
