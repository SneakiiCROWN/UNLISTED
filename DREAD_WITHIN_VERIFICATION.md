## Two authored consequences of the restored lounge

Both use the existing ambient scheduler and its long seeded quiet intervals,
spatial eligibility, encounter reservations and once-only saved consumption.
They require the player to have witnessed the impossible room, seen it restored
and revisited it. They are optional aftermath, never required progression.

1. **The curtains have closed.** Only when the room is unoccupied and both the
   existing and destination curtain volume are hidden, the actual pleated cloth
   widens along its existing pole. A quiet positional ring contact can draw
   attention back. Doorway and exterior-glazing sightlines protect the change.
   The completed dressing remains on revisits and visible save/load. It is not
   a figure spawning behind the glass, an automatic chase or an animated reveal.
   Native review also exposed the old frame and sill intersecting the widened
   cloth. The final construction hangs inside the mullions and drapes over the
   sill; normal shadow casting remains enabled. The unsuccessful no-shadow
   experiment and earlier intersecting captures are preserved separately.
2. **Footsteps above a normal room.** After the same witnessed restoration, one
   measured passage crosses above the lounge ceiling, followed by a pause and
   quiet wood contact. This echoes the existing 1998 account of overhead walking
   without identifying its source or adding a new character. The furniture stays
   on the floor. There is no forced camera, music stinger or explanatory popup.

Pause freezes timing; simulated controller Start/B is checked. Reduced motion
retains static dressing and sound. Sound captions are optional. Partial reload
consumes an interrupted optional sound rather than replaying it. Pending authored
encounters cancel queued cues. Legacy saves without the optional usage keys
restore open curtains and retain all existing investigation conditions.

Visibility rays now run only when a scheduling draw is due, rather than on every
physics tick throughout an 82-160-second cooldown. Explicit F1/test requests still
recheck current eligibility. No altered seed weights for old event IDs, no extra
event controller and no claim of a measured CPU speedup without a matched benchmark.

## Native crash preserved; not declared fixed

Final candidate 08's first foreground moving profile exited with Windows access
violation 0xC0000005 while walking after a live render-resolution change. It did
not finish or write a performance report and is not a passing run. The Windows
Application record names NVIDIA nvoglv64.dll, driver 32.0.16.2101, fault offset
0xFAAA9F. This identifies where the failure surfaced, not its root cause and not
proof that the game is blameless. Owner saves/settings remained unchanged.

Earlier candidate 06 completed the same profile. Candidate 08's gameplay,
room-memory, event, vent, recorder and ending fixtures completed independently.
The exact same 08 executable is repeated once in isolation, with original logs
and Windows crash record preserved. DELIVERY.json records that result. Even if
the repeat passes, this intermittent native failure remains unresolved and must
not be described as repaired. No public release.
